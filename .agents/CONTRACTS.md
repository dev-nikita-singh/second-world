**sw-shared notes (Batch A, READY 2026-10-29):**
- `RingBuffer`: capacity rounded up to a power of two; options `{ grow?, overwrite? }`. `push` returns true when stored without loss, false when rejected (full) **or** when it overwrote the oldest (value is still stored; `dropped` counts drops). Extra: `pop()`, `peekLast()`, `at(i)` (negative ok), `clear()`, iterable, `isFull`, `isEmpty`.
- `Semaphore`: extra `max`, `inUse`. FIFO strict: `tryAcquire()` returns null while waiters are queued (no barging). Already-aborted signal rejects immediately with `signal.reason`.
- `LatencyHistogram`: extras `recordCount(us, n)`, `clamped` counter, `clone()`, `footprintBytes`, `lowestUs/highestUs/digits`. NaN/negative → 0, > highestUs → highestUs (both counted in `clamped`). Empty → all zeros. `add()` throws RangeError only if the other's values exceed this range. `max` after decode/merge is bucket-equivalent (≤0.1% above the exact max).
- `WindowedSeries`: options `{ windowMs=1000, maxWindows=3600, foldFactor=60, maxCoarseWindows=1440, histogramWindows=120, histogramCoarseWindows=60, histogram={digits:2}, totalHistogram={digits:3} }`. Window type `SeriesWindow { startMs, endMs, histogram: LatencyHistogram | null, ok, failed, bytes, summary: LatencySummary | null }` — histogram is **null** for gap windows and for closed windows older than `histogramWindows` (summary is kept). Extras: `record(nowMs, latencyUs, ok, bytes?)` (updates current window + `total` histogram + `totalOk/totalFailed/totalBytes`), `flush(nowMs)`, `closeAll()`, `coarse()`, `lastClosed()`, `rolling(n, includeOpen?) → LatencyHistogram`. Gaps are filled with empty windows.
- `Ewma`: `update(x, nowMs)` returns the new value; first sample initialises; Δt ≤ 0 leaves value unchanged. Extras `initialized`, `reset()`.
- `Reservoir`: extras `size`, `reset()`; `offer` returns whether the item was kept.
- util: `ulid(timeMs?)`, `createUlidFactory(prng?)`, `isUlid`, `ulidTime` (`util/ulid.ts`); `sha256`, `fnv1a` (uint32), `fnv1aHex` (`util/hash.ts`); `fingerprint(parts)` accepts string|number|boolean|null|undefined, 16 hex (`util/fingerprint.ts`); `backoff({base,cap,attempt,rng})`, `backoffCeiling` (`util/backoff.ts`).
